CircleCI Labs

Open projects built by CircleCI field engineers with customers

Working solutions for problems that customers hit and the product does not cover. Each project is open source, with its own docs.

See the projects GitHub organization

Projects

  • Machine runner swarm

    Self-hosted CircleCI runners that give every job a clean container, on the Docker hosts you already run. Linux and Windows Server, no Kubernetes. An experimental add-on runs jobs in microVMs.

    Status: Pre-release (0.x). Linux and Windows Server tested, microVM experimental.

    Documentation GitHub repository

About

  • Every project is open source under the MIT license, with a public repository and a docs site.
  • Each project states its maturity: tested, experimental, or not tested.
  • Labs projects are not CircleCI products. Interfaces can change between releases.

Support

CircleCI support does not cover Labs projects. Field engineers handle issues on a best-effort basis, without an SLA.
