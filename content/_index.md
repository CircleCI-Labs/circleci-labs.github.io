## About

CircleCI Labs is a collection of solutions that CircleCI field engineers built through their work with customers.

- Every project is open source under the MIT license, with a public repository and a docs site.
- Each project states its maturity: tested, experimental, or not tested.
- Labs projects are not CircleCI products. Interfaces can change between releases.

## Support

CircleCI Support does not cover Labs projects. Field engineers handle issues on a best-effort basis, without an SLA.

| You have | Go to |
|---|---|
| A bug or a feature request for a Labs project | The GitHub issues of that project |
| A question or an idea | [CircleCI Discuss](https://discuss.circleci.com/) |
| A problem with the CircleCI platform or the runner agent | [CircleCI Support](https://support.circleci.com/hc/en-us) |
| A security vulnerability | [security@circleci.com](mailto:security@circleci.com), never a public issue |
